# Akash_Portfolio# Akash Patra — Digital Signature Portfolio

A **personal, editorial‑style portfolio** showcasing the work of **Akash Patra**, a multidisciplinary designer specializing in:

- **Website & Landing Page Design**  
- **UI/UX Design**  
- **Creative Development**  
- **Brand Identity Design**  

The site is built with **React**, **TypeScript**, **Vite**, and **GSAP**, and follows a cinematic, motion‑driven visual language that emphasizes bold serif typography, near‑black backgrounds, and a warm terracotta accent.

### 🎬 Key Features

- **Cinematic Hero & Scroll‑Triggered Animations** – title‑sequence‑style reveals, layered typography, and GSAP‑driven scroll choreography.  
- **Interactive Project Showcase** – The EVE case study includes real screenshots, a live iframe preview, and a custom “Canvas Engine / 401 Frames” badge.  
- **Progressive Web App (PWA)** – Installable on desktop & mobile, supports offline navigation, precaches core assets, and provides a graceful fallback for the external iframe.  
- **Responsive Design** – Optimized layouts for desktop, tablet, and mobile without sacrificing visual fidelity.  
- **Modular Data Structure** – All personal information, capabilities, navigation, and projects live in a single `siteData.ts` (or `portfolioData.json`) for easy updates.
